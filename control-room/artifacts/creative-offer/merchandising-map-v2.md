# Merchandising Map v2

## Material change
- **Kit Muda Cero remains HERO**, but the current 3-piece supplier path is too tight to treat as launch-ready. Keep the full 3-step offer behind Finance + fulfillment gates.
- Add a **2-piece grooming-core contingency** (glove + self-cleaning slicker) as **CORE** for modeling only. It must use a narrower grooming/prevention promise and must not launch without Finance approval.
- **Hard-bottom dog car cover / backseat extender remains the second HERO candidate**, but “hard bottom” alone is no longer differentiation. Lead with exact dimensions, measurement UX, belt/seat access and real structural proof.
- **Compression packing cubes remain TEST** only.
- **Windshield umbrella becomes seasonal CROSS-SELL**, not HERO and not a paid-acquisition priority.

## Collection architecture

### 1. Mascotas en casa
Promise: **Menos pelo suelto. Menos pelo repartido.**

1. Kit Muda Cero full 3-step — **HERO** — €39.90 first / €34.90 secondary, only if economics clear.
2. Muda Cero grooming core (2-piece contingency) — **CORE** — Finance to model €34.90 first / €29.90 second.
3. Reusable pet-hair roller — **CROSS-SELL** — EU origin/SLA + same-shipment gate.
4. Pet deodorizing cleaning gloves — **UPSELL** — claims/compliance gate.
5. Pet grooming vacuum — **TEST** — electrical/compliance gate.

Hooks:
- “3 problemas. 3 herramientas. Una rutina.”
- “El pelo no se resuelve con una sola herramienta.”
- “Primero el manto. Después el sofá.”

UGC:
Real pet + real textile. Map one tool to one job and end with visible collected hair. No universal-surface claim.

### 2. Mascotas en movimiento
Promise: **Viajar con ellos sin entregarles el coche.**

1. Hard-bottom dog car cover / backseat extender — **HERO** — €59.90 first / €69.90 secondary.
2. Portable pet water bottle — **CROSS-SELL**.
3. Reusable pet-hair roller — **CROSS-SELL** only if fulfillment can be consolidated.

Hooks:
- “Antes de comprarla, mide esto.”
- “¿De verdad queda plana? Te lo enseñamos.”

UGC:
Measure the real rear seat, install the exact SKU, show the rigid platform, seat/belt access and realistic dog use. Do not make unsupported safety or load claims.

### 3. Viaje y coche
Status: **INCUBATOR**. Keep the category in the architecture but do not give it top-level launch prominence until it has 3 credible SKUs or 1 HERO + 2 coherent complements.

1. Compression packing cubes — **TEST**.
2. Foldable windshield sunshade umbrella — **CROSS-SELL**, seasonal only.
3. Handheld vacuum sealer — **TEST**, compliance/sourcing gated.

Hooks:
- Packing cubes: “La misma ropa. La misma maleta. ¿Cierra o no?”
- Sunshade: “Mide el parabrisas antes de comprar.”

UGC:
Packing cubes use a fixed clothing list and the same carry-on before/after. Sunshade shows real deployment, dimensions and dashboard/mirror clearance.

## Bundle hypotheses
- **Muda Cero Completo:** glove + slicker + reusable roller. Gate: full economics + coherent fulfillment.
- **Muda Cero grooming core:** glove + slicker. Contingency only; narrower promise.
- **Pack Viaje Limpio:** hard-bottom cover + water bottle + roller. Gate: same-shipment economics + verified fit/specs.

Never show artificial reference pricing or bundle savings before real standalone prices, shipping and availability are verified.
